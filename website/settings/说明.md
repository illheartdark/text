# settings —— 设置功能
**功能：** 声明本文件夹的内容
**编号：** 28

## 本文件夹内容

- `settings.css`：设置面板全部样式——遮罩、展开 / 收起动画、手机全屏 / 电脑弹窗、账户行、主题卡片、框选画面与预览
- `settings.js`：设置核心（UMD，浏览器全局 `SettingsApp`，Node 可测试纯函数）——主题加载 / 应用 / 持久化、设置面板树形层级导航、账户区块 UI、主题列表与「识别本地文件」、壁纸式框选调整与预览

## 说明

- 使用前必须在页面声明 `window.THEMES_BASE` 基准路径常量（首页 `themes/`，src 下页面 `../../themes/`），本文件夹内不涉及主题图片。
- settings.js 在三个层级页面均引用：首页额外初始化设置面板；详情页 / 游戏页只执行「主题应用」部分。
- 主题注册表与各主题内容见 `../themes/`（30）。
- 本地以 `file://` 双击打开时浏览器禁止 fetch，主题注册表不可读，页面保持默认玻璃主题；本地预览请用静态服务器（如 `python -m http.server`）。
