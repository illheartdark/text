# themes —— 主题
**功能：** 声明本文件夹的内容
**编号：** 30

## 本文件夹内容

- `index.json`：主题注册表（id 数组），新增主题必须在此登记一项
- `<themeId>/theme.json`：主题清单（id、name、preview、mobile / desktop 图片与 fit、cssVars 可选）
- `<themeId>/mobile/bg.jpg`：手机专用背景图
- `<themeId>/desktop/bg.jpg`：电脑专用背景图
- `<themeId>/preview.jpg`：列表缩略图（可选）

当前主题：glass（默认玻璃拟态，无图片，兜底）、aurora（示例主题，程序生成渐变壁纸）。

## 新增主题三步接入（不碰任何代码）

1. 新建 `<themeId>/` 文件夹：theme.json + mobile / desktop 图片（可选 preview）。
2. 在 `index.json` 的数组中登记该 id。
3. 首页设置 → 主题 → 点「识别本地文件」刷新即可出现并可用。

## 主题清单字段（theme.json）

- `id`：字符串，必须与文件夹同名。
- `name`：显示名。
- `preview`：预览图相对路径（可选）。
- `mobile` / `desktop`：各一个对象 `{ "image": "mobile/bg.jpg", "fit": "cover" }`（image 可为 null 表示该设备沿用默认）。
- `cssVars`：可选对象，覆盖配色变量（如 --accent-cyan）。
