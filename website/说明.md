# website —— 网站代码
**功能：** 声明本文件夹的内容
**编号：** 8

## 本文件夹内容

整个网站的代码，纯静态实现（零依赖，无需安装任何包）：

- `index.html`：第 1 层首页（游戏大厅）
- `src/`：源代码（全局样式、可复用部件、页面逻辑、游戏、公共工具）
- `tests/`：自动化测试
- `settings/`：设置功能（设置面板与主题应用脚本，编号 28-29）
- `themes/`：主题（注册表 + 各主题清单与壁纸，编号 30-31）

## 目录约定

每个子文件夹都包含 `说明.md`（内容声明，编号见 agent.md 对照表）和 `修改日记.md`（修改记录，编号见 agent.md 对照表）。

## 使用方法

- 直接双击 `index.html` 即可打开首页。
- 本地预览：在 website 目录启动任意静态服务器（如 `python -m http.server`）后访问首页。
- 主题应用依赖 fetch 读取 `themes/index.json`：请使用 http(s) 环境（本地静态服务器或线上）；直接双击打开（file://）时浏览器禁止 fetch，保持默认玻璃主题。
- 运行测试：`node --test "website/tests/*.test.js"`。
