# 网站设计文档（v0.1.0）

- 日期：2026-08-12
- 状态：设计已获用户确认，目录结构已批准，代码待实现

## 1. 项目目标

一个简单的小游戏网站，共 3 个层级：

1. **第 1 层 · 首页（游戏大厅）**：选择小游戏、登录入口。
2. **第 2 层 · 游戏详情页**：游戏介绍、难度选择、开始游戏按钮。
3. **第 3 层 · 游戏本体**：实际游玩。

第一版（v0.1.0）只包含贪吃蛇一个游戏。

## 2. 三层结构与跳转

- 首页 `index.html` → 点击游戏卡片 → `src/games/snake/index.html`（详情页）
- 详情页选择难度后点“开始游戏” → `src/games/snake/play.html`（游戏页）
- 游戏页可返回详情页或首页

## 3. 首页设计

- **背景**：玻璃拟态——深色渐变 + 彩色线条（青/紫/粉）流动动画 + 光晕光影，纯 CSS 实现，不使用图片。
- **卡片**：半透明毛玻璃卡片，鼠标划过时跟随鼠标轻微倾斜与浮动。
- **内容**：网站标题、游戏卡片（名称 + 一句话简介，不放“开始游戏”按钮）、右上角登录入口（v0.1.0 仅样式占位）。

## 4. 技术方案

- Vite + 原生 HTML/CSS/JS（不引入前端框架）。
- 多页面结构：`index.html` / `src/games/snake/index.html` / `src/games/snake/play.html`。
- 贪吃蛇核心逻辑独立为 `core.js`，不依赖 DOM，可单独测试。

## 5. 目录结构与约定

```
program1/
├─ website/          网站代码（独立 Vite 项目）
│  ├─ index.html     第 1 层首页
│  ├─ package.json
│  ├─ vite.config.js
│  ├─ src/
│  │  ├─ styles/     全局样式（base / glass / home）
│  │  ├─ components/ 可复用部件（game-card / auth-entry）
│  │  ├─ pages/      页面逻辑（home.js）
│  │  ├─ games/      小游戏（snake/：index 详情页、play 游戏页、core 核心逻辑）
│  │  └─ shared/     公共工具（navigation / storage）
│  └─ tests/         自动化测试
└─ docs/             项目文档
```

约定：

- 根目录 `program1` 只允许新增文件夹，不允许新增文件。
- 每个文件夹包含 `说明.md`（内容声明）与 `修改日记.md`（修改记录）。

## 6. 贪吃蛇功能清单

- Canvas 渲染、方向键控制、计分、最高分（本地记录）。
- 难度：简单 / 普通 / 困难（对应不同速度）。
- 暂停、重开、结束判定、返回。
